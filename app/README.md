### useViewportSize - React Hook для отслеживания размеров окна браузера

Хук useViewportSize позволяет отслеживать изменения размеров окна браузера (viewport) в реальном времени.

### API

Возвращаемое значение
Объект со следующими свойствами:

Параметр Тип Описание
width number Текущая ширина окна в пикселях
height number Текущая высота окна в пикселях

### Особенности

Автоматическое обновление: хук подписывается на события resize и orientationchange
SSR-совместимость: безопасная работа на серверной стороне
Оптимизированная производительность: автоматическая отписка от событий при размонтировании компонента
Типобезопасность: полная поддержка TypeScript

## Внутренняя реализация

# Хук состоит из двух частей:

Вспомогательный хук useWindowEvent:
Добавляет обработчики событий к объекту window
Автоматически удаляет их при размонтировании
Полностью типизирован для всех стандартных событий window

# Основной хук useViewportSize:

Хранит текущие размеры окна в состоянии
Обновляет состояние при изменении размеров
Возвращает актуальные значения ширины и высоты
