📄 useToggle – React Hook для переключения между значениями
Гибкий хук для циклического переключения между значениями (по умолчанию true/false).
Поддерживает:
✅ Произвольные значения (строки, числа, объекты)
✅ Принудительную установку конкретного значения
✅ Кастомный начальный набор значений

🔧 API

Возвращаемое значение
[currentValue, toggleFunction]

currentValue – текущее значение из массива

toggleFunction:

Без аргументов – переключает на следующее значение

С аргументом – устанавливает конкретное значение (если оно есть в массиве)

🧠 Особенности реализации

1. Использует useReducer
   Позволяет централизованно управлять сложной логикой состояний.

2. Защита от невалидных значений
   При попытке установить значение вне массива – состояние не меняется.

3. Стабильная ссылка на функцию
   Функция toggle мемоизирована и не меняется при ререндерах.
