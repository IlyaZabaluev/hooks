### useLocalStorage — React-хук для работы с localStorage

Хук useLocalStorage предоставляет удобный интерфейс для чтения, записи и удаления данных из localStorage в React-компонентах. Он автоматически синхронизирует состояние с localStorage и обрабатывает возможные ошибки.

### Возвращаемое значение

Хук возвращает массив из двух элементов:
Текущее значение (string | null) — значение из localStorage или null, если ключ не найден.

Методы:
setItem(value: string) — сохраняет значение в localStorage.
removeItem() — удаляет значение из localStorage.

### Особенности

Синхронизация: При изменении ключа хук автоматически обновляет значение.

Обработка ошибок: Все операции с localStorage обернуты в try-catch, ошибки выводятся в консоль.
