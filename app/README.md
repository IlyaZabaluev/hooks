### useFetch — React-хук для удобной работы с HTTP-запросами

Хук useFetch предоставляет простой интерфейс для выполнения GET-запросов в React-компонентах. Он включает обработку состояний загрузки, ошибок и данных, а также возможность повторного запроса с новыми параметрами.

### Особенности

Автоматический запрос: По умолчанию запрос выполняется при монтировании компонента
Типизация: Поддержка TypeScript
Повторный запрос: Возможность обновления данных с новыми параметрами
Обработка ошибок: Автоматический capture и передача ошибок
